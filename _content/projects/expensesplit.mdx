ExpenseSplit is an expense-sharing platform built with React.js, NestJS, PostgreSQL, Redis, Drizzle ORM and Docker.

- Workspace-based multi-tenancy with Google OAuth and JWT authentication.
- CI/CD automation and OpenAPI-driven API contracts.
- A debt-simplification algorithm that computes net balances and minimizes the number of settlement transactions.
