Meditor is a Markdown editor built with Neutrino.js, React.js and SQLite.

- Integrated local LLM inference for document summarization.
- A knowledge vault using Retrieval-Augmented Generation (RAG) to retrieve relevant notes and generate context-aware answers to user queries.
